Quellen

Diese Archive braucht AmiDevIDE, um die Toolchain zu bauen. Normalerweise holt sie bootstrap/acd_fetch.py automatisch — diese Seite ist der manuelle Weg, falls der Rechner offline ist oder ein Server klemmt.

Generiert am 27.09.2026 aus bootstrap/sources.toml. Nicht von Hand bearbeiten.

So geht der manuelle Weg

  1. Die Archive unten herunterladen.
  2. Unverändert nach var/downloads/ legen — nicht entpacken, nicht umbenennen.
  3. Bootstrap starten: 
    cmake --build build --target acd-toolchain
    oder direkt: 
    python3 bootstrap/acd_fetch.py --offline
python3 bootstrap/acd_build_tools.py
python3 bootstrap/acd_install_sdk.py
python3 bootstrap/acd_gen_config.py

Bereits Entpacktes wird erkannt. Liegt ein Quellbaum schon unter var/src/ oder ein SDK unter toolchain/sdk/, wird der jeweilige Schritt übersprungen. Du kannst also auch eine bestehende Installation von Hand hineinkopieren.

Auf Aktualität prüfen

python3 bootstrap/acd_fetch.py --check-updates   # meldet, ändert nichts
python3 bootstrap/acd_fetch.py --update          # zieht + schreibt sources.lock.json fort

Entpacken

.lha braucht ein Werkzeug, das nicht überall vorhanden ist. acd_extract.py probiert der Reihe nach lha, lhasa, 7z und zuletzt das Python-Modul lhafile. Wenn nichts davon da ist:

pip3 install lhafile          # portabel, keine Systempakete nötig
# oder
brew install lhasa            # macOS
sudo apt install lhasa        # Debian/Ubuntu
pacman -S mingw-w64-x86_64-p7zip   # MSYS2
